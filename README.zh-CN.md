# VbeComplete — VBA 变量名/过程名自动补全工具

*[English](README.md) · **简体中文***

![VbeComplete 实际效果：输入 "cus" 实时过滤候选，Tab 确认补全](assets/demo.gif)

VBE（VBA 编辑器）原生只对 `对象.成员` 弹列表，**不对你自己起的变量名/过程名弹列表**。
本工具补的就是这一块：在代码窗输入名字的前几个字符（或中文首字，如 `Dim 用户名 As String`），
候选列表实时弹出并过滤，`Tab` 确认、`↑`/`↓` 选择、`Esc` 取消。

支持 **Office 全家桶**（Excel / Word / PowerPoint / Access / Visio）与 **WPS 全家桶**
（文字 / 表格 / 演示），按前台窗口自动识别当前宿主，无需配置。

## 注意事项

1. **Windows** + 上面任一宿主。
2. **Python 3.8 及以上**（推荐 3.10 ~ 3.12）。装官方版时勾选 *Add python.exe to PATH*。
   Python 3.13 也能跑，`pip` 会自动装 ≥ 308 的 `pywin32`。
3. **必须**在你用的那个宿主里勾选"信任对 VBA 工程对象模型的访问"，然后**重启该应用** ——
   不勾选工具完全读不到代码：
   **文件 → 选项 → 信任中心 → 信任中心设置 → 宏设置 → 勾选该项**。
   （这一项和"启用宏"是两回事，只调宏安全级别没用。WPS 在自己的选项里有同名开关。）
4. 首次运行需要联网装依赖（`pywin32` / `pynput`），之后启动瞬间完成。
5. **改了代码必须重启进程**：Python 在启动时把 `.py` 读进内存，只覆盖文件不重启，
   跑的仍是旧代码 ⇒ 一律 **`stop.bat` → 覆盖文件 → `run.bat`**。

## 安装与运行

```bat
git clone https://github.com/CoffeeBean001/VbeComplete-V587.git
cd VbeComplete-V587
run.bat
```

`run.bat` 首次会装依赖，然后**后台静默运行**。想看输出就在命令行跑 `python main.py`。

装完打开 VBE（`Alt+F11`），在代码窗敲自己某个变量名的前几个字母，列表就会出现在光标旁边。

- `stop.bat` — 结束后台进程
- `run_tests.bat` — 跑回归测试
- `install_autostart.bat` / `uninstall_autostart.bat` — 加 / 撤开机自启
  （在「启动」目录放一个指向 `pythonw main.py` 的快捷方式；工具是焦点驱动的，
  平时不挂全局钩子，切到 VBE 才生效）

## 使用

### 快捷键

| 操作 | 作用 |
| --- | --- |
| 输入字母 / 数字 / `_` | 弹出候选列表并实时过滤 |
| `↑` / `↓` | 上下选择（循环），一屏放不下时自动滚动 |
| `Shift+↑` / `Shift+↓` | 收起列表，同时把光标上/下移一行 |
| `Tab` | **确认补全**（唯一确认键） |
| 单击候选 | 用鼠标确认 |
| `Esc` / `←` / `→` / 点击别处 | 收起列表（方向键照常移动光标） |
| `Ctrl+Space` | 强制弹出 |
| `Enter`（行尾） | 换行 + 智能缩进；块头自动补 `End Sub` / `Next i` 等收尾 |
| `Shift+Enter` | 在当前行下方新起一行（不把本行拆开），缩进判定同回车 |
| `Backspace` | ① 整行只有空白时一下删掉整行；② 光标在空括号/空引号正中间时两端同删 |

### 确认之后

- `Sub` 补一个空格，`Function` 补 `()` 并把光标放在括号里，`Property` 不补，关键字补空格。
- 在 `Function` 体内给函数**自己**赋返回值（`MyFunc = 5`）时，那个名字是变量，不补括号。

### 会提示哪些名字

- 工程里的变量 / 常量 / 过程（`Sub` / `Function` / `Property`）/ 模块 / 窗体 / 控件名。
- 没有 `Option Explicit` 时，"用过但没声明"的变量也提示。
- VBA 关键字与内建函数 / 数据类型（约 260 个）默认收；**枚举（`vb*` / `xl*` / `mso*`）刻意不收**。
- 可见性跟随 VBA 作用域，只提示光标处够得着的名字。

### 不弹列表？

- **先查第 3 条注意事项**（信任设置），九成是这个；勾了要重启应用。
- 任务管理器里看有没有 `pythonw.exe`，没有就再跑一次 `run.bat`。
- 列表关不掉 / 什么都补：多半是残留了旧实例，`stop.bat` 再 `run.bat`。
- 在 `With` 块里敲 `.成员` 什么都不弹：这个位置**刻意让给 VBE 自己的**成员列表，
  它需要能解析出对象类型 —— 先把工程编译一遍（**调试 → 编译**）。
- **正在定义**新变量/过程名（`Dim …`、`Sub …`）时不弹，和 IDEA 一致：那会儿是在造新名字，
  没有可补的东西；`As` / `New` 后面的类型位置照常提示。

## 跑回归测试

```bat
run_tests.bat
```

用 `tests/testdata/` 里一份真实工程导出的 14 个模块离线跑，**不需要 Office / COM**。
少数用例会真读当前宿主的类型库并断言 Excel 专属常量名，宿主不是 Excel 时自动跳过。
