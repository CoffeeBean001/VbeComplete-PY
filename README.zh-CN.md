# VbeComplete · Python 版

*[English](README.md) · 简体中文*

VBE 原生只对 `对象.成员` 弹列表，**从不补全你自己声明的**变量、常量、过程、窗体名。
本工具补的就是这一块：敲名字的前几个字符（支持中文名，如 `Dim 用户名 As String`），
光标旁立刻弹出候选列表。支持 **Office 全家桶**（Excel / Word / PowerPoint / Access / Visio）
与 **WPS 全家桶**，按前台窗口自动识别宿主。

![输入 "cus" 实时过滤候选，Tab 确认补全](assets/demo.gif)

## 功能

- **实时候选**：标识符 / 声明 / 过程 / 模块 / 窗体 / 控件 / 关键字 / 内建函数，边打边过滤，
  每条候选前面带类型小图标。
- **智能确认**：`Tab` 补全；`Sub` 补一个空格，`Function` 补 `()` 并把光标放进括号里，
  关键字后面补空格。
- **回车自动缩进**：块结构开头自动深一级并补上对应的 `End If` / `Next` / `Loop`；
  `Else` / `Case` 这类分支行先拉回层级再决定下一行。
- **`Shift+Enter`**：在当前行下方新起一行，不把本行拆开。
- **退格两用**：整行只有空白时一下删掉整行；光标夹在空括号 / 空引号中间时两端同删。
- **自动配对** `(` `"`：输入法在中文标点 / 全角时补的是 `（）` / `“”`；右边已是收符号就
  "跨过去"；有选区时用符号把选区包起来。
- **行操作快捷键**：`Ctrl+/` 注释切换 · `Ctrl+D` 复制行 · `Ctrl+K` 删行 ·
  `Ctrl+Shift+Enter` 上方插行 · `Ctrl+Shift+↑/↓` 跳到上一条声明 / 过程收尾行。
- **`Ctrl+Q` 代码片段库**（SQLite 两列：标题 / 代码，标题模糊搜索，插入到光标处）。
- **自动恢复**：心跳 + `watchdog.py`，进程卡死或被杀后几秒内自动拉起。
- **自适应轮询**：打字时 50ms、停手 150ms、不在 VBE 里 250ms。

## 优点

- 补的是**你自己工程里**的符号，不是一张固定词表；中文变量名同样能补。
- Office 全家桶 + WPS 通用，一套功能不用分家。
- 宿主忙、进程卡死或被误杀都能自己恢复，不必重启电脑。
- 开销可控：在 VBE 里静止时约占 **2% 的一个核**、内存 **46MB**。
- 所有快捷键遵守同一条铁律：**做不成就把原按键原样还回去**，不会出现"吞了键却什么都没发生"。

## 缺点

- **只支持 Windows**，且需要安装 **Python 3.8+**。
- 必须勾选"信任对 VBA 工程对象模型的访问"（默认关闭），否则完全读不到代码。
- 那 **2% 的一个核是 Tk 事件循环的地板**，离开 VBE 也不会降下去。
- 不提供参数信息提示；宿主枚举常量（`vb*` / `xl*` / `mso*`）刻意不收录。
- 全局钩子只在 VBE 获得焦点时挂载：别的编辑器里没有补全，切回 VBE 也有一小段延迟。
- 改了 `.py` 源码必须 `stop.bat` → `run.bat` 重启，没有热重载。
